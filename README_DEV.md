# Restricted AREA — Dev Documentation & Lore Guide

## 📌 Идея и Концепция
`Restricted AREA` — это интерактивный веб-проект в стиле **Hostile / Anti-UX UI**, маскирующийся под странную интернет-аномалию. 

Сайт чист с точки зрения безопасности (антивирусы молчат, вредоносного кода нет), но ломает привычный пользовательский опыт, вызывая чувство тревоги и исследовательской паранойи.

---

## 📖 Сюжетная лор-составляющая (для разработчика)

### 1. Точка входа (Reddit)
* **Контекст:** Главный герой (посетитель) ночной порой скроллит сабреддиты со странными находками (`r/deepintoweb`, `r/UnresolvedMysteries`).
* **Пост:** Попадает на полузаброшенный тред от пользователя `[deleted]` с заголовком: 
  > *"Found this weird IP domain from 2004. Looks harmless, but inspect element shows encrypted loops. Anyone seen this?"*
* **Переход:** Автор поста удален, ветка заблокирована модераторами. Из любопытства герой кликает по ссылке.

### 2. Первая фаза: «Обманчивое спокойствие»
* **Визуальный ряд:** Пастельные тона, скучная верстка конца 2000-х (архив какого-то научно-исследовательского института или старый сайт техобслуживания).
* **Безопасность:** Зеленый индикатор в углу браузера. Никаких вирусов.
* **Аномалия:** В правом нижнем углу экрана (или за границей фоновой картинки) слегка мерцает и дёргается мелкий кусок CSS-сетки. 

### 3. Вторая фаза: «Спуск в Restricted AREA» (Триггер)
* **Действие:** Пользователь не удерживается и кликает по глючащему пиксельному куску.
* **Реакция системы:**
  * Спокойный дизайн «трескается» или сползает вниз, как порванное полотно.
  * Включается «враждебный» интерфейс: жёлто-чёрные ленты ограничений (DANGER / RESTRICTED), знаки радиации/биоугрозы, летящие вниз или падающие при клике элементы интерфейса.
  * Сайт переходит в режим "защиты от чужака".

## 🛠 Архитектура элементов и UX-ловушек

1. **Падающие блоки:** При попытке нажатия на некоторые меню или тексты гравитация «ломает» их (CSS-анимация / JS-физика).
2. **Лента ограничения:** Границы сайта перекрыты лентой, за которую физически нельзя проскроллить без взаимодействия с артефактами.
3. **Отказ навигации:** Попытка вернуться «наверх» или закрыть окно приводит к появлению системных предупреждений лора.
4. **Консоль (F12):** Зашифрованные логи для тех, кто полезет в `DevTools`.
